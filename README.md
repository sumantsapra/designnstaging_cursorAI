# Design & Staging Website

Standalone, modern static site for the boutique IT consultancy Design & Staging
(designnstaging.com).

## Tech Stack
- HTML5 + semantic layout
- Modern CSS (responsive grid, CSS variables, clamp typography)
- Vanilla JavaScript (navigation toggle, year)

## Site Structure
- `index.html`: primary landing page with service overview and CTA
- `about.html`: story, values, and industry focus
- `services.html`: service catalogue and engagement models
- `work.html`: outcomes and case study highlights
- `insights.html`: thought-leadership teasers
- `contact.html`: direct email contact (no form)
- `assets/css/styles.css`: shared styling
- `assets/js/main.js`: minimal interactivity

## Content Focus
All copy is AI-generated to encourage visitors to engage and learn more about the
firm, with clear calls to email `info@designnstaging.com`.
